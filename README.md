# EcoDesk Static Site

Этот репозиторий содержит одну страницу `index.html` и необходимые ресурсы (картинки, шрифты и т.п.) для лендинга EcoDesk.

## Запуск локально

1. Откройте файл `index.html` в браузере двойным кликом или через `File → Open`.
2. Если вы хотите протестировать дополнительные JavaScript‑функции (слайдер, модальные окна), убедитесь, что браузер разрешает выполнение inline‑скриптов.

> _Совет:_ в Internet Explorer и некоторые сборки Edge могут блокировать скрипты при прямом открытии, но большинство современных браузеров (Chrome, Firefox, Edge (Chromium), Safari) работают корректно.

## Подготовка к хостингу

1. Переименуйте корневую папку так, чтобы в имени не было пробелов и кириллических символов. Например: `ecodesk-site`.
2. Убедитесь, что внутри каталога находятся файлы:
   - `index.html`
   - все используемые изображения (`facier.svg`, `PUTP.png`, `stol1.png`, `stol2.png`, `stol3.png` и т.п.)
3. Залейте содержимое папки на любой статический хостинг:
   - GitHub Pages (разместите репозиторий с `index.html` в корне);
   - Netlify (перетащите папку или подключите репозиторий);
   - Vercel, Firebase Hosting, GitLab Pages, любой `ftp`/`sftp` и т.п.

Сайт работает без серверной части — достаточно простого HTTP/HTTPS. В файле уже указан `<base href="./">`, поэтому вы можете разместить его в поддиректории (например `https://example.com/desk/`) и все относительные пути останутся корректными.

> 🔧 **Важно**: если хостинг автоматически добавляет префикс (например `https://user.github.io/repo-name/`), проверьте, что файл `index.html` находится в корне этого репозитория и что вложенные ресурсы не вынесены в другую папку без корректировки путей.

## Добавление новых ресурсов

Для того чтобы добавить дополнительные изображения или скрипты, положите их в папку и указывайте путь вида `./имя-файла.ext`.

## Дальнейшие шаги

Если вы планируете расширять сайт и добавлять серверную логику (форма, корзина и т.п.), лучше перевести проект на статический генератор или фреймворк с возможностью бэкенда. Но для простого лендинга всё готово.
